Общие правила: агент не правит чужие файлы, не запускает Gradle (сборка одна,
после всех лейнов), проверяет `git diff --check`. Строки каждого блока — в
своём `values*/strings_wave3_<блок>.xml`, чтобы параллельные лейны не
конфликтовали в общем `strings.xml`.

Общие гарантии, которые нельзя ослабить: обновление Ventoy не пишет раздел 1;
установка Ventoy по-прежнему требует подтверждения и форматирует данные;
подтверждения и проверки LBA/геометрии сохраняются; RO/RW — фактическое
состояние, а не политика.

## Material Design и практики UI

Все пункты реализуются по Material 3, а не «на глаз»:

- **Цвета и состояния:** недоступное — `onSurface` 0.38 (контент) и 0.12
  (контейнер), без серых заливок поверх пунктов; красный (`error`) — только
  ошибки и деструктивные подтверждения; `primary` — основные действия.
- **Поверхности:** меню и диалоги — `surfaceContainerHigh`; полоса статуса —
  `surface` с `outlineVariant` 1 dp, без карточки и тени.
- **Размеры:** интерактивные цели не меньше 48 dp (иконки-кнопки 48 dp,
  строка пути 48 dp); визуальная толщина может быть меньше, чем цель.
- **Типографика:** заголовки `titleMedium`, тело `bodyMedium`, подписи
  `labelMedium/labelSmall`; иерархия через роль токена, а не через ручной
  размер шрифта.
- **Диалоги:** `AlertDialog`/`Dialog` с заголовком, телом и действиями
  (подтверждение справа), крестик закрытия — только когда закрытие безопасно.
- **Выравнивание:** одинаковые базовые линии в строке, `Arrangement.spacedBy`
  вместо ручных отступов, `WindowInsets` не дублируются.
- **Доступность:** `contentDescription` у иконок-кнопок, `stateDescription` у
  переключателей, семантика выбора, поддержка fontScale 2.0 без обрезки.
- **Анимации:** только смена состояния, без «прыжков» контента; уважать
  reduced motion.
