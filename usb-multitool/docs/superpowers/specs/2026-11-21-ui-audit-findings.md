## Осталось: ниже приоритетом

- Files: FAB — 48 dp `FilledIconButton`, не M3 56/40 dp; dialog outline/elevation
  переопределены вручную; часть строк использует `bodyMedium/bodySmall` вместо
  `ListItem`-типографики.
- Partitions: Start LBA/Size без numeric IME и объяснения ошибки; edge labels слайдера
  могут столкнуться при 2×; RAW overlap details отбрасываются; разделители фактов —
  `outlineVariant.copy(alpha=0.1f)`; Create Continue не учитывает `state.actionsEnabled`;
  капсула схемы — текст, не иконки PAR-02/03.
- Shell: уровни журнала не локализованы и классифицируются по английским словам; индикатор
  выбранной вкладки `surfaceContainerHigh` почти не отличается от фона; заголовки Settings/
  Diagnostics без `heading()`; danger-текст Diagnostics дублируется; overflow-меню при
  running открывается без доступных действий.
- Ventoy: скачанный release не показан, хотя help обещает его; VTY-06 direction только в
  `contentDescription`; Replace-кнопка нейтральная; GLS-03 custom JSON path не оранжевый;
  GLS-06 нет clear «×» у полей; WIN-07 unknown elements не перечислены; WIN-02 нет
  selected/generated статуса.

## Конфликты, требующие решения

1. **RO-цвет.** Текущий amber `#FFC46B/#8A5300` (`WriteAccessTone.kt:18-26`) против
   старого FILE-06 «RO красным». Не менял: красный в текущей дизайн-системе — только
   ошибки/деструктивные действия.
2. **Карта разделов.** Точная LBA-геометрия и отказ от искусственного 48 dp — текущее
   решение; PAR-05/06 требуют минимальной ширины/касания. Нужно выбрать: точность или
   гарантированный touch.
3. **Статус.** Новое указание — постоянная строка + диалог; старые GEN-06/07 (стрелка,
   крестик, круг у nav, авто-раскрытие) не реализованы. Считаю конфликтом, не дефектом.
4. **Селектор разделов.** Текущая шторка/закреплённая полоса vs полноширинный dropdown над
   контентом. Переделка затрагивает `PartitionsScreen`, не Files.
5. **GLS-03.** Старое требование оранжевого custom JSON path; текущий код намеренно
   использует обычный `onSurface` и документирует это.
6. **VTY-04.** Сейчас refresh-иконка; старое примечание просило download-иконку.
7. **PAR-09/11/14.** Sticky selected partition, корзина в шапке карточки, создание как
   элемент списка — не реализованы; текущие решения отличаются.
8. **Заголовок.** Версия/тема/язык не рядом с версией, журнал — иконка; мёртвые
   `ProjectVersionButton`/`LanguagePicker`/`ThemeToggle`.
