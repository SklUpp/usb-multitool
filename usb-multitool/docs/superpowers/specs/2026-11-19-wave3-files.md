# Файлы: иконки, строка пути, RO/RW, меню, отступ снизу

## F1. Иконки

Применить дуотон-набор там, где есть соответствие: файл, ISO, копирование,
обновление, стоп, «ещё», воспроизведение. Папка, корзина, стрелки, шевроны,
плюс, карандаш в наборе отсутствуют — оставить текущие и не рисовать новые.
Стилистическая цельность важнее буквального «заменить всё».

## F2. Строка пути

Строка пути центрируется по вертикали относительно иконок «Назад»,
«Обновить», «Создать папку»: одна базовая линия, одинаковая высота 48 dp,
без висящего вверх текста. `StartEllipsis` сохраняется.

## F3. RO/RW

- Показывается только `RO` или `RW`, без слов «политика», «драйвер» и любых
  других подписей рядом.
- RO отличается цветом везде, где выводится: общий нейтральный контейнер,
  `primary` для RW, отдельный цвет текста для RO. Красный — только ошибки.
- Длинные описания остаются в `contentDescription`, не на экране.

## F4. Отступ снизу

Последний блок списка файлов не прилипает к навигационной панели: нижний
отступ не меньше 16 dp сверх высоты панели.

## F5. Меню и диалоги

Убрать резкое «серый контейнер > чёрный фон»: меню и диалоги на
`surfaceContainerHigh`, без заливки пунктов фоном. Недоступный пункт
приглушается только текстом и иконкой (`onSurface` 0.38), без серой плашки на
весь пункт. Относится ко всем меню в экране «Файлы», включая меню трёх точек.

## Владение

`usb/ui/FilesScreen.kt`; при необходимости `usb/ui/FilesPickScreen.kt`.
Строки — новый `values/strings_wave3_files.xml` и `values-ru/strings_wave3_files.xml`.
Не править `AppShell.kt`; если общий стиль меню живёт там — описать находку в
отчёте, решение примет владелец оболочки.

## Приёмка

- Иконки в списке и панели — из набора, где он есть; новых рисунков нет.
- Строка пути визуально на одной линии с иконками (проверить по компоновке).
- В UI нет слов рядом с RO/RW; RO и RW различаются цветом.
- Над навбаром есть отступ.
- Недоступные пункты меню — серый текст, не серая плашка.
- `git diff --check` чист; строки EN/RU совпадают.
