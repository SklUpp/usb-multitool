# Аудит кода 2026-11-20

Три независимых read-only скаута: жизненный цикл USB/claim, безопасность данных, Compose-состояние и доступность. Проверялись реальные пути вызовов, а не имена. Физическое устройство недоступно, поэтому выводы — статическая проверка + существующие тесты; это отмечено в статусах.

## P1

| Находка | Статус |
|---|---|
| Утечка process-wide USB claim и открытого fd при teardown: `measureFilesystemUsage` может войти в `synchronized` уже после `onCleared` и смонитровать том, чей continuation мёртв; закрытия нет. Повторный запуск в том же процессе получает Busy. `MainActivity.kt:3049-3117`, `FilesVolumeSession.kt:395-487` | исправлено |

## P2

| Находка | Статус |
|---|---|
| `onCleared` закрывает files-том синхронно на main, пока операция держит мокс с блокирующим USB I/O | исправлено |
| Probe/refresh классифицируют любой `DiskException` (Busy, sense, unsupported) как «отключено» | исправлено |
| `PartitionWriter.commit` не перечитывает и не сравнивает записанные primary/backup GPT (MBR — список разделов); возможен «успех» на короткой записи | исправлено |
| `GptBackup` жёстко считает 128×128 entries; нестандартная CRC-валидная GPT захватывает сектора данных и восстанавливает их | исправлено |
| SAF-загрузки завершаются без `fsync`; успех не означает долговечность | исправлено |
| Files: действия записи включены на томе, который UI помечает RO (`DriverReadOnly`) | исправлено |
| Диалог перезаписи импорта недостижим с других вкладок, при этом новые импорты блокируются | не исправлено: диалоги живут в Ventoy/Files, нужен перенос в AppShell; отмечено к следующей волне |

## Проверка

`compileDebugKotlin`, `compileDebugUnitTestKotlin`, адресные unit-тесты и `lintDebug` прошли локально с системным AAPT2. Полный выбранный набор завершился ошибкой: шесть тестов `SafBackupFolderOwnershipTest` не запустились из-за отсутствия `libpthread.so.0` у Robolectric/conscrypt на Termux. После исключения этого класса остальные выбранные тесты и lint завершились успешно. `FilesOperationsBatchTest` с Robolectric локально не запускался; проверка на CI необходима.

## Что проверено без замечаний

- Raw range plan/writer: границы, end-exclusive, overflow, readback, Partial.
- GPT/MBR парсинг, bounds, CRC, backup relocation, TableInitializer.
- Ventoy install/update геометрия и запреты записи в VTOYEFI.
- SAF staging, fsync staging, canonicalization.
- Claim/lease/mount epoch fence и детач-resubmit исполнителя (кроме teardown-окна выше).
- Snackbar/статус, логи, reducer guards, EN/RU parity волн 3-5.
