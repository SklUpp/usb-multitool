# Второе ревью: что применено, что отклонено, почему

Источник — список улучшений от 2026-11-19 (UI, UX/безопасность, данные,
низкоуровневые инварианты). Решения пользователя: статус остаётся постоянной
строкой сверху с центральным диалогом; диапазон секторов остаётся в списке
разделов.

## Применено

- **Иерархия кнопок Ventoy:** установка — заполненная `errorContainer`,
  обновление — иконка в заголовке без error-цвета.
- **Меню:** `surfaceContainerHigh` + `shadowElevation = 3.dp` (устройство,
  язык, выбор раздела в «Файлах»); строки меню и листов больше не заливаются
  серым, недоступное приглушается только текст/иконка 0.38.
- **Статус:** грамматика — номинативные названия операций в строке и диалоге
  (`status_title_*`), винительный падеж остался только в подтверждениях.
  Повторяющаяся фраза «установку … · готово» больше не появляется.
- **Помощь:** тело разбито на короткие блоки с `**жирным**`, кнопка закрытия —
  `FilledTonalButton`.
- **Слайдеры настроек:** подпись и текущее значение рядом со стандартным
  `Slider`, привязка к тем же полям.
- **Посекторная запись:** путь к образу — `OutlinedTextField` с меткой вместо
  тёмного прямоугольника; точный ручной ввод LBA остаётся главным, карта —
  дополнительный индикатор с привязкой.
- **EFI:** подсказка указывает на переключатель на том же экране; защита,
  подтверждение и guard сохранены.
- **Удаление раздела:** иконка из шапки убрана, полноширинная деструктивная
  кнопка внизу карточки, подтверждение называет раздел и размер.
- **VTOYEFI:** отображение EFI/загрузочный исправлено на уровне представления,
  флаги таблицы и политика защиты не меняются.
- **RO/RW:** единый тон (`WriteAccessTone.kt`): RW — `primary`, RO — янтарный,
  контейнер нейтральный, рядом только `RO`/`RW`, красный не используется.

## Уже было реализовано (проверено по коду, менять не нужно)

- Отключение USB прерывает операцию без debounce и без повторного
  использования подтверждения старого поколения.
- Ошибка записи по BOT не повторяется, сессия закрывается, результат `Partial`.
- Для чтения допустим reset recovery с одной повторной попыткой.
- Eject: `sync` → `close` → `SYNCHRONIZE CACHE(10)` → `disk.close`, без
  обещания физического сброса кэша.
- `PARTIAL_WAKE_LOCK` только на время длительной операции; короткие чтения
  сервис не поднимают (решение пользователя, сохранено).
- Размер SAF-образа читается через `Os.fstat`, неизвестные ключи ventoy.json
  сохраняются.

## Отклонено с обоснованием

- **Статус в bottomBar + ModalBottomSheet** — противоречит решению волны 3
  (постоянная строка под заголовком, окно по центру); окно снизу перекрывалось
  бы журналом и снова прятало отмену.
- **Убрать LBA из списка разделов** — противоречит волне 3 (строка
  `сектор X–Y (N секторов)` признана нужной). LBA остаётся и в списке, и в
  карточке.
- **Дублирующий статус под шапкой** — одна строка, без второго артефакта; текст
  исправлен грамматически, а не удалён.
- **Зелёный для успеха в журнале** — в палитре нет зелёного токена; успех
  показывается `primary`, красный остаётся только для ошибок. Добавление
  зелёного — отдельное решение о палитре.

## Не найдено в текущем дереве

- Чекбоксы выбора цели в посекторной записи (выбор уже одиночный в состоянии);
- `DropdownMenu` выбора раздела в «Разделах» (меню живёт в «Файлах»);
- отдельная полоса статуса в `bottomBar` — её нет с волны 3.
